## Observed source-content risks

The existing public website contains conflicting names, generic template copy and placeholder content. Those claims are not carried forward. Founder biography, client endorsements, project locations, awards, legal entity details and numerical claims remain excluded until verified.

## Website objective

Position Sequoia as a calm, design-led premium landscape practice and convert qualified visitors into consultation conversations.

## Information architecture

1. Home — positioning, capabilities, selected environments, process and primary conversion.
2. Studio — point of view, principles and working method.
3. Services — six clear service categories and delivery process.
4. Projects — portfolio-ready editorial gallery using clearly labelled design-direction imagery.
5. Contact — enquiry form plus direct phone, email and WhatsApp routes.

## Technical architecture

- Next.js App Router with TypeScript.
- React 19 component model.
- Tailwind CSS v4 utilities plus a token-led global brand layer.
- Framer Motion for entrances, navigation and scroll progress, respecting reduced-motion preferences.
- Static export for portable hosting.
- Local imagery with static-export-compatible delivery.
- No server actions, cookies, database or hidden backend dependency.

## Acceptance gates

- The approved logo is not redrawn, recoloured or distorted.
- Copy contains no unverified founders, testimonials, clients, awards or project claims.
- All routes export to static HTML.
- Navigation, contact actions and enquiry handoff work without a server.
- Desktop, tablet and mobile layouts receive visual QA.
- Lint, type checking and production build pass before handoff.
